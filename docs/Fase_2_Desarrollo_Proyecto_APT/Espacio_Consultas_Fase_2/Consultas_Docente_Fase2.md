### Consulta 1: Formato de Evidencias de Bloqueo
* **Pregunta planteada:**  
  *¿Es suficiente presentar capturas de pantalla de la interfaz web de pfSense para validar el bloqueo de Suricata, o se deben adjuntar volcados de la tabla `pfctl` desde la consola de FreeBSD?*
* **Respuesta / Criterio Docente:**  
  *Se exige evidencia técnica a nivel de sistema operativo: salidas por consola de `pfctl -t snort2c -T show`, registros estructurados de `eve.json` y capturas de paquetes que demuestren el TCP Reset o Drop inmediato.*
